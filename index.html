영수증 한 장으로 시작하는 AI 냉장고 관리 · 맞춤 레시피 추천 앱

캡스톤디자인 · 2인 팀 · 2026.03 ~ 진행 중
내 역할: 안드로이드 앱 개발 (팀원: Spring Boot 백엔드 · DB · AI 연동)

소개

가정에서 음식물쓰레기가 가장 많이 나온다는 문제에서 출발한 프로젝트입니다. 영수증을 촬영하면 식재료가 자동으로 등록되고, 유통기한이 임박한 재료를 우선 활용하는 맞춤 레시피를 추천해 줍니다. 저는 안드로이드 앱 전체를 맡아 화면 설계부터 서버 연동까지 구현했습니다.

주요 기능

  • 냉장고 관리: 식재료 추가·수정·삭제, 유통기한 D-day 표시, 임박순 정렬
  • 영수증 스캔: CameraX로 영수증을 촬영해 서버로 전송, AI가 식재료명 추출
  • 맞춤 레시피 추천: 보유 재료 일치율 순 정렬, 알레르기 14종·식단 목적 5종 반영
  • 한국어 / English 전환

기술 스택

  • Android: Java, Material 3, Room, Retrofit2, CameraX, ML Kit
  • Backend(팀원): Spring Boot, JPA, Oracle DB
  • AI·데이터: Claude API(서버에서만 호출), 식약처 조리식품 레시피 공공데이터 1,156건

문제 해결

  • 사용자 데이터 혼재: 앱은 userId를 보냈지만 서버가 무시해 모든 사용자의 재료가 섞였습니다. 서버에 userId 컬럼과 사용자별 필터를 추가해 해결했습니다.
  • API 키 노출 위험: 앱에 AI API 키를 넣으면 APK 디컴파일로 키가 노출될 수 있어, 영수증 분석을 서버 경유로 바꾸고 키는 서버에만 보관했습니다.
  • 영문 레시피 매칭 문제: 영문 데이터로는 한국어 재료명이 매칭되지 않아 한국어 공공데이터로 교체하고, 영문 결과는 ML Kit으로 자동 번역했습니다.
  • 앱·서버 데이터 동기화: 앱 로컬 DB(Room)와 서버 데이터를 id로 연결해 수정·삭제가 양쪽에 반영되도록 했습니다.

진행 현황

  • 완료: 냉장고 관리, 영수증 촬영·전송 화면, 레시피 추천·상세, 개인 설정, 한/영 전환
  • 진행·예정: 영수증 AI 인식 연동 테스트, 유통기한 임박 알림, AI 대화형 레시피 질문
